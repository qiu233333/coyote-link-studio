## 自动化测试

`pnpm test`：44 项全部通过，覆盖以下边界：

- 官方 SDK 的 V3/V4 模拟中继：扫码内容、发现和选择设备、强度转换、短波形发送。
- 显式模拟设备、波形协议和上限校验。
- 急停清理顺序、停止回传确认、超时不重试、不虚构归零。
- 启动、暂停、连接与急停的并发；旧响应不能恢复输出。
- 三类控制权互斥、锁定期间修改拒绝、启动幂等。
- AI 反馈取消旧决策、暂停修改范围、运行时中断后停止。
- 后台截止、暂停期间截止、重启标记中断且不恢复。
- 固定随机种子、授权行为、阶段保持/间隔/渐变、列表跳项和暂停恢复。
- 本机 Host/Origin/会话验证、WebSocket 实际推送、API Key 加密与脱敏。
- 真正的 eve 子进程通过本地 OpenAI 兼容接口桩测试聊天、工具调用、草稿、范围拒绝、内部鉴权及取消。
- 设备 20/19 回传不扩大默认零授权；显式保存设备上限或较低数值后才允许非零播放，保存动作不产生输出。
- 所选通道、启用状态和同步取低值；运行中编辑单通道不扩大到另一通道，关闭再启用原选通道保留选择且不会自行恢复非零目标，运行/暂停/锁定期间上限与速率不可更改。
- 设备降限对目标和渐变状态动态限幅，排队指令与启动归零后重新校验；实际强度超新边界时故障归零。

## 浏览器端到端

运行 `pnpm verify:browser`。测试使用临时数据库、显式模拟设备和本地兼容模型接口桩，不使用真实 API Key 或真实设备。

实际通过六组流程：

1. 设置页保存配置并测试聊天与工具调用。
2. 控制台连接模拟设备，设置通道上限，单波形开始后观察到非零回传，再停止。
3. 普通 AI 控制确认启动、文字反馈、暂停、修改范围、恢复和手动接管。
4. AI 上锁任务生成草稿、修改、确认开启，检查控制台只读和后端写请求返回 423。
5. 上锁期间发送反馈，使用急停终止，观察到通道归零。
6. 检查窄屏布局无横向溢出，紧急停止可见。

本轮浏览器验证产生 8 次实际本地模型接口请求，未预期的页面异常、控制台错误和 HTTP 错误均为 0。预期的锁定写请求 423 被单独记录。

## 控制台上限专项回归

运行 `pnpm verify:limits`。使用 `mkdtemp` 独立数据目录、`listen(0)` 随机端口、明确选择的模拟设备，以及进程内 AI 接口桩验证锁定；所有浏览器请求限定本次应用来源。未访问主工作区 `127.0.0.1:3000`，未停止或重启主服务，未使用真实设备、真实密钥或原数据库。

9 组流程全部通过：

1. 回传设备 A/B=20/19，用户设置仍为 0；三种上限和配置入口可见，播放器提示未授权并禁用开始。
2. 绕过界面直接请求非零播放也被后端拒绝，未创建运行。
3. A 明确采用设备上限，B 输入较低数值再保存；保存不输出，播放器按单选或双选显示对应上限。
4. 同步要求双选、启用和授权两个通道，采用较低上限；禁用通道有明确原因，单通道独立播放可用。
5. 确认弹窗打开后设备上限下降，确认按钮立即禁用。
6. 确认开始后才出现模拟输出，运行与暂停期间上限和速率禁改，后端返回 409。
7. 运行中设备降限会限制后续目标并保持同步低值；回传已超过新边界时故障归零，用户授权保持原值。
8. 上锁任务的上限和速率只读，后端返回 423，急停解锁且确认归零。
9. 未配置与已配置状态的桌面及 390px 页面无横向溢出，急停可见，保留蓝粉玻璃风。

未预期的页面异常、控制台或 HTTP 错误均为 0。原 `pnpm verify:browser` 的完整 AI 流程也再次通过，实际本地模型接口请求为 8 次。

结果：`artifacts/limits/verification.json`。截图：`unconfigured-desktop.png`、`unconfigured-mobile.png`、`running-desktop.png`、`lowered-limits-desktop.png`、`locked-desktop.png`、`configured-mobile.png`（均在 `artifacts/limits/`）。
