## 下载与启动

下载 **`Coyote-Link-v0.3.1-windows-x64.zip`**，完整解压后双击 `Start-Coyote.cmd`。支持 Windows 10/11 x64，包内包含 Node.js 和 AI 运行时。可用同名 `.sha256` 附件校验 ZIP。

## 本版更新

- **控制台界面**采用更鲜明的蓝粉配色，侧栏融入页面背景。正文与主要按钮更易读，设备回传和目标强度清楚区分。A/B 通道各有波形预览，实时强度图用实线和虚线区分两路回传。
- **AI 控制和上锁任务**突出授权范围与当前步骤。AI 动作卡可以查看动作目标和设备实际回传。
- **情景演绎**新增故事状态面板、书签和剧情分支。支持流式回复、玩家快捷回复，并可分别设置 A/B 初始联动强度，暂停后按确认的目标恢复。
- **编辑体验**改进状态同步，编辑中的草稿可在切换页面后继续。README 增补了安装、模拟设备试播、APP 配对和模型配置步骤。

## 升级

先在网页紧急停止并核对设备状态，再运行 `Stop-Coyote.cmd` 退出旧版后台。备份整个 `data/`，将新版解压到新目录，再复制原来的 `data/`。数据库和 `installation.key` 需要一同保留。

发布验收使用模拟设备和本地模型测试接口。[安装与迁移说明](https://github.com/qiu233333/coyote-link-studio/blob/v0.3.1/docs/PORTABLE.md)
